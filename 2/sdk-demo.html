📍 text2dom - Wstawianie do DOM

            
Wstaw wygenerowany HTML do strony za pomocą języka naturalnego:

            
            

// Przykład użycia text2dom
const json_data = [
    { name: "Jan", age: 25, city: "Warszawa" },
    { name: "Anna", age: 30, city: "Kraków" }
];

// Generuj tabelę i wstaw na dole strony
text2dom(
    "Umieść html na dole strony",
    text2html("wygeneruj tabele z danych", json_data)
);

// Lub krócej z dataToTable
text2dom("dodaj na górze #output-container", dataToTable(json_data));

🔄 Pipeline - Łańcuch operacji

            
Wykonaj wiele operacji w sekwencji:

            
            

const nlp = new NLP2CMD('http://localhost:8001');

const result = await nlp.pipeline([
    { converter: "text2html", command: "generate form for login" },    // GENERATE
    { converter: "text3html", command: "add remember me checkbox" }  // EDIT
]);

text2dom("wstaw do #output-container", result.final_output);
            

            
            
        


        
        

            
🎨 text2style - Stylowanie elementów

            
Zmień style elementów za pomocą języka naturalnego:

            
            

// Styluj element

📚 API Reference

            
            
Funkcje GENERATE (text2X)

            

text2html(command, data?)      // Generuj HTML
text2markdown(command, data?) // Generuj Markdown
text2svg(command, data?)      // Generuj SVG
text2json(command, schema?)   // Generuj JSON
text2css(command)             // Generuj CSS
            

            
            
Funkcje EDIT (text3X)

            

text3html(command, html)      // Edytuj HTML
text3markdown(command, md)    // Edytuj Markdown
text3css(command, css)        // Edytuj CSS
            

            
            
Funkcje DOM

            

text2dom(placement, html)     // Wstaw do DOM
text2style(styles, element)   // Styluj element
text2query(query)             // Znajdź elementy
            

            
            
Utilities

            

dataToTable(data, options?)   // Konwertuj dane do tabeli HTML
dataToList(data, options?)    // Konwertuj dane do listy HTML
nlp2cmdConfig({ apiUrl })    // Konfiguruj SDK
